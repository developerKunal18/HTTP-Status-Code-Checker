# HTTP Status Code Checker

A Python script that checks the status codes of multiple URLs.

## Description
This project reads URLs from a file and checks whether each website is reachable.

## Features
- Batch URL checking
- HTTP status code display
- Useful for uptime monitoring

## Technologies Used
- Python
- urllib module

## How to Run
1. Clone the repository
2. Add URLs to urls.txt
3. Run:

   python status_checker.py

## Example

Output:
https://google.com → 200 OK  
https://example.com → 200 OK
